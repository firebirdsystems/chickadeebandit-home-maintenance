# Home Maintenance

A [Chickadee Bandit](http://chickadeebandit.com) app.

Track recurring maintenance tasks — car oil changes, HVAC filters, appliance servicing — with full history and document storage for warranty PDFs and manuals.

## Features

- Define tasks with custom recurrence intervals (e.g. every 3 months, every 5 000 miles)
- Log completions with notes and date
- Full history per task
- Attach warranty PDFs and manuals to each item
- Color-coded urgency when tasks are coming due or overdue

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-home-maintenance/releases/latest/download/bundle.json
```
